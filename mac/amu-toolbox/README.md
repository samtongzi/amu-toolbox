# 阿木工具箱

Windows 离线工具商城，提供工具介绍、搜索与分类、按需安装、启动、卸载和便携版导出。界面采用浅色毛玻璃风格；支持的 Windows 11 系统使用 Acrylic 背景，旧系统使用浅色渐变背景。

内置 App 更新监测器 1.0.4 与 Codex 额度重置通知 1.0.2。安装和导出无需联网；两个工具运行时访问各自的数据来源。额度提醒是 divin.cc 的公开重置事件提醒，并非个人账户额度查询。

## 使用

- 打开“阿木工具箱-安装版-1.0.0.exe”安装工具箱，或直接运行便携版。
- 在“工具商店”选择需要的工具，点击“安装”。安装后从“我的应用”或 Windows 开始菜单启动。
- 工具详情中的“导出便携版”可保存独立 EXE，复制到其他电脑即可使用。
- “下载管理”显示本次会话的安装、导出、卸载任务和结果，复制过程中可以取消。
- 卸载前需先从子工具的托盘退出。卸载保留子工具配置与历史；原先单独保存的工具不会被删除。
- 工具安装到 `%LOCALAPPDATA%\AmuToolbox\apps`，开始菜单快捷方式位于“阿木工具箱”文件夹。
- 工具箱与子工具独立运行。卸载工具箱不会自动删除子工具；可先在“我的应用”卸载不需要的工具。

这是离线版本，不包含服务器、在线商城账户或自动获取新发布包的服务。发布新工具版本时重新生成内置目录并分发新版工具箱。

## 开发与构建

```powershell
npm install
npm run prepare:packages
npm test
npm start
npm run build
```

`scripts/prepare-packages.cjs` 从相邻的两个项目 release 目录复制发布包，生成带大小与 SHA-256 的 catalog.json。更新子工具后先运行该脚本。请确保源项目的 package.json 版本和发布 EXE 版本一致。

输出位于 release，包含当前用户安装版和便携版。每次安装/导出校验完整包，不执行远程脚本。界面运行于隔离、沙箱化的 Electron 渲染进程，所有文件操作由主进程按固定工具目录处理。

开发时可设置 `AMU_TOOLBOX_TEST_ROOT` 到临时测试目录，使安装与快捷方式写入该目录；正式打包版本忽略这个变量。
