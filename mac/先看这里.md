# 阿木工具箱 · Apple Silicon 构建包

此包是源码及构建脚本，包含阿木工具箱、App 更新监测器、Codex 额度重置通知。
只生成 macOS arm64，不生成 Intel 或 Universal 版本。Windows EXE 没有放入此包。

## 在 M 芯片 Mac 上生成安装包

1. 解压整个文件夹到 Mac 的下载或文稿目录。
2. 使用原生 ARM64 Node.js 22 或 24 LTS：https://nodejs.org/ 。此构建包在 Node.js 26 下可能无法完整解压 Electron；已安装多个版本时，请将 LTS 的 bin 目录放在 PATH 首位。
3. 在终端运行 `xcode-select --install`，等待命令行工具安装完成（已安装则跳过）。
4. 打开终端，输入 `bash `（末尾一个空格），把本文件夹里的 `build-mac.command` 拖入终端，回车。

脚本会自动安装依赖、运行测试、构建两个工具、将工具安装包内置到工具箱，再生成 DMG 和 ZIP。
首次构建需要联网，下载 Electron 可能较慢。脚本不需要 sudo，不会安装 Homebrew 或修改系统安全设置。
日志自动写入 logs 文件夹。失败时把最新日志发来即可排查，修复环境后可重新运行脚本。

## 构建完成后

output 文件夹会自动打开，包含：

- `amu-toolbox-1.1.2-mac-arm64.dmg`：打开后把阿木工具箱拖进 Applications，再从 Applications 启动。
- `amu-toolbox-1.1.2-mac-arm64.zip`：工具箱压缩包。
- `app-update-monitor-1.1.2-mac-arm64.zip`：可独立使用的更新监测器。
- `codex-reset-notifier-1.0.6-mac-arm64.zip`：可独立使用的额度通知。
- `SHA256SUMS.txt`：产物校验值。

最低 macOS 12，M1/M2/M3/M4 等 Apple Silicon。程序只有 arm64，无需 Rosetta。
安装工具不需要联网，工具自身扫描或获取额度动态需要联网。
工具箱把独立工具安装在 `~/Applications/阿木工具箱/<工具标识>/`，可在“我的应用”打开、定位或卸载。
卸载前请从屏幕顶部菜单栏退出工具；卸载保留配置和历史，并关闭该工具的登录启动。
卸载工具箱本身不会移除已经安装的工具。

## Mac 外观

工具箱左侧栏、更新监测器的维护设置均可选择“浅色、深色、跟随系统”，选择后自动保存，各应用独立记住偏好。跟随系统会随 macOS 外观即时变化。新版提高毛玻璃面板遮蔽程度，加深浅色模式的小字，并提供深色专用配色。额度通知沿用 macOS 系统通知样式。

## Mac 版更新监测器

监测器扫描 /Applications 和个人 Applications 中的 App，通过应用官网更新源、官方发布清单和 App Store 查询检查更新，不运行 Homebrew 检查。支持 Claude 官方发布清单，MacWhisper 等更新源通过 macOS 系统网络访问并遵守现有代理设置；不会修改代理或绕过 hosts 屏蔽。
仅显示确认有更新的应用；HTTP 错误、连接失败或暂无可识别更新源的应用会静默跳过。App Store 查询当前支持中国及美国商店。
Sublime Text 按构建号比较并核对最低 macOS 要求；官网被 hosts 或网络规则屏蔽时会静默跳过，不绕过本机网络配置。
默认只在菜单栏运行，不显示 Dock 图标；点击“显示主界面”打开窗口。列表展示应用原图标，支持勾选多款官网应用并行下载与安装，显示各项进度、失败原因及重试入口。ZIP/DMG 安装包须通过应用身份、版本、开发者签名、系统安全评估与架构校验；替换后校验失败将恢复原应用。请先退出待更新应用。App Store 及不兼容的安装包仍通过原有更新入口完成。

## Mac 版额度通知

启动后查看屏幕顶部的秒表图标。可立即检查、开启登录启动或退出。
Mac 版使用右上角系统通知中心，请在系统设置的通知页允许此应用发送通知；可从托盘菜单打开通知设置。登录启动默认关闭。此工具读取 divin.cc 的公开重置记录，不读取个人账户额度。

## 验证范围与签名

已在本机 Mac 上完成逻辑测试、构建和界面验证；批量安装通过隔离测试验证，未替用户升级第三方应用。
构建末尾自动核对 arm64 架构、应用签名、内置工具包大小和 SHA-256。首次使用请验证：
工具箱安装/导出/打开/卸载；更新监测器刷新与单项更新；额度工具监控状态及登录启动。
本包默认使用本机 ad-hoc 签名，不需要 Apple 开发者证书；这不等于 Developer ID 签名或 Apple 公证。
适合在你的 Mac 上构建和测试。公开分发给其他用户前，应改用 Developer ID 并完成公证。
不要关闭 Gatekeeper 或系统完整性保护；如系统阻止运行，请把提示原文反馈给作者。

## 开发与同步

源码保留 Windows/Mac 平台分支。三个项目继续使用各自的 `npm run build` 构建 Windows；
在 Mac 上运行顶层脚本可同步重新生成两个工具及工具箱。
Mac 打包配置为各项目 `build.mac.cjs`，目录数据由 `prepare-mac-packages.cjs` 自动生成。
工具箱未生成 Mac 目录前请先完整运行一次构建脚本。

参考：Homebrew 命令文档 https://docs.brew.sh/Manpage ，Electron Builder https://www.electron.build/ 。

## 1.1.1 修正

通知显示应用名称和目标版本，同一版本跨失败扫描、手动刷新与重启只提醒一次；同批更新合并通知。旧提醒记录自动迁移。菜单栏采用 18 点原生系统符号；工具箱采用独立的 52 点标题栏，使窗口控制按钮与下方磨砂侧栏错开。图标通过 scripts/generate-tray-icons.swift 生成 1x/2x/3x 资源。

## 1.1.2 修正

修复 Claude 等 Electron 应用安装包解压时出现 `Invalid package ... app.asar`。安装器使用物理文件读写保留 ASAR 原始内容，应用自身的 ASAR 支持保持开启；增加真实 Electron 环境中的解压、完整性、替换和回滚回归测试。
