# App 更新监测器

Windows 桌面工具，用于查看 `winget` 可识别的本机应用更新，并按单项、选中项或全部更新。批量更新可在设置中配置为最多 5 款软件同时执行。

## 功能

- 打开后扫描可更新应用并显示当前版本、可用版本和来源
- 单项更新、更新选中项、更新全部、取消和失败重试
- 设置 1–5 款软件并发更新；右击单个软件可忽略更新，并可从设置中恢复
- 更新后重新扫描确认结果，必要时等待 2 秒、5 秒再复查（最多三次，仅复查，不重复安装）
- 核对目标版本，排除过期或不完整扫描；无法确认时显示“待确认”，后续刷新自动纠正结果
- 后台定时扫描、新增更新通知、托盘和开机启动
- portable Windows 可执行文件

程序只覆盖 `winget` 能识别的软件，不会自动安装更新。所有更新都必须由用户主动触发。

## 开发

需要 Node.js 22+ 和 Windows Package Manager (`winget`)。

```bash
npm install
npm test
npm run start:mock
npm start
npm run build
```

`start:mock` 使用固定的模拟数据，不会调用 winget 或更改本机软件。`npm start` 会执行真实只读扫描；只有点击更新按钮后才会执行安装。
