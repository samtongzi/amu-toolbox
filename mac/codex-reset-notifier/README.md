# Codex 额度重置通知

Windows 托盘小插件，每 5 分钟检查一次 [divin.cc](https://divin.cc/) 的公开 Codex 额度重置记录。发现新的 Codex 额度重置事件后，通过右下角紧凑的毛玻璃通知卡片提醒。

通知宽 360 逻辑像素、左右内边距 15 像素，高度随内容调整，支持系统深浅色。Windows 11 22H2 及以上使用原生 Acrylic 背景模糊，较旧系统使用清晰的半透明底色。12 秒后自动关闭，鼠标悬停或键盘操作时暂停；点击正文或“查看详情”打开来源，关闭按钮或 Esc 收起。多条通知依次显示，关闭通知不会退出后台监控。

自定义卡片不写入 Windows 通知中心。界面加载失败时回退到原生系统通知，避免漏掉提醒。

## 行为

- 第一次成功检查只建立历史基线，不弹出旧记录。
- 以后按事件 `id` 去重，不会因排序或内容变化重复提醒。
- 只提醒明确的额度变更类别，不会把“重置次数功能发布”误报成额度重置。
- 网络异常、返回格式错误时只更新托盘状态，下一周期自动重试。
- 默认随 Windows 登录启动，可从托盘菜单关闭。
- 点击通知可打开记录来源；不安全或缺失的来源会打开 divin.cc 首页。

## 开发运行

需要 Node.js 22 或更高版本：

```bash
npm install
npm test
npm start
```

首次开发运行不会注册 Electron 开发程序为 Windows 开机启动项。程序仅在发现新的有效重置事件时发送提醒，不提供测试通知入口或测试启动参数。

## 构建便携版

```bash
npm run build
```

输出文件位于 `release/Codex额度重置通知.exe`。程序不需要安装，复制到目标位置后直接运行即可。未签名的 Windows 程序在其他电脑上可能触发 SmartScreen 提示。

## 数据来源

程序只读取 `GET https://divin.cc/api/reset-events`，不需要登录，也不会嵌入或自动操作网页。
